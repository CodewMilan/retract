Client setup

Install Retract's Python package, then configure the MCP command as retract mcp. Set RETRACT_URL to this workspace's HTTPS address and RETRACT_API_KEY to your access key in the client's environment.

Keep keys out of source control. Revoking a key stops new requests immediately.
